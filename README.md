# 护输宝

**只使用 Chatterfly 的语音输入，保留自己习惯的输入法。**

这个小工具会记住你正在使用的输入法，在启动 Chatterfly 的语音输入时切换回之前的输入法，而不影响 Chatterfly 的语音输入。

如果有一天 Chatterfly 更新后，可以像 Typeless 等输入法一样，在不切换当前输入法的情况下进行语音输入，该工具即停止维护。

**愿免费好用的 Chatterfly 永存！**

## 下载与使用

1. 从 [最新版本](https://github.com/f-is-h/chatterfly-input-guard/releases/latest) 下载 ZIP 并解压。
2. 将 **护输宝.app** 拖入“应用程序”文件夹，再双击打开。
3. 应用图标使用“護”字。菜单栏出现 **護** 后，照常按 Fn 开始和结束 Chatterfly 语音输入。

支持 macOS 13 及以上，发布包同时包含 Apple 芯片和 Intel 版本。首次运行默认开启“登录时启动”，可在“護”的菜单中关闭。系统若要求允许登录项，按菜单提示前往系统设置。

应用尚未经过 Apple 公证。首次打开若被系统阻止，请按 [Apple 的说明](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”中选择“仍要打开”。请只下载本仓库发布的版本。

## 菜单里有什么

- 查看当前恢复目标，暂停或恢复自动切回。
- 开关登录启动和自动检查更新。
- 手动检查更新和打开 GitHub 仓库。

自动更新检查每天最多一次，只读取本仓库的最新正式 Release；发现新版后显示 **護↑**，由你下载替换。不会自动下载或安装。退出旧版后，用新版覆盖“应用程序”里的同名应用，再打开即可。

## 工作方式与边界

- 只匹配 Chatterfly；完全不用它打字的人最适合使用。
- 监听输入法变化，不监听 Fn，不读取输入文字、录音或剪贴板，也不需要辅助功能权限。
- 这是切换后的自动恢复，输入法图标仍可能短暂变化。
- 记不清上一个输入法时，先手动选择一次常用输入法即可。
- 连续恢复失败会暂停保护，菜单会显示原因；选择常用输入法后可手动恢复。
- 日志只记录运行状态、输入法标识和更新检查结果，保存在 `~/Library/Logs/ChatterflyInputGuard/`，自动限制大小。

已在 Apple 芯片的 macOS 27 上验证输入法自动恢复；macOS 13–26 和 Intel 实机尚未验证。不同 Chatterfly 版本的语音行为可能变化，遇到问题可先退出守护工具。

## 从源码构建

安装 Xcode 或 Command Line Tools 后，在仓库目录执行：

```sh
bash scripts/build.sh
```

产物在 `dist/`：应用、ZIP 和 SHA-256 校验文件。实现只有一个 Swift 源文件，使用 macOS 自带接口，无第三方依赖。
